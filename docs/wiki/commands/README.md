# Solix CLI Commands Reference

This section documents the subcommands and flags provided by the Solix toolchain (`solix`):

* [**`compile` & `build`**](file:///home/jehud/Projects/solix-language/docs/wiki/commands/compile-and-build.md): Standalone file compilation and full project build orchestration (`manifest.toml`).
* [**`run` & `info`**](file:///home/jehud/Projects/solix-language/docs/wiki/commands/run-and-info.md): Executing bytecode containers and inspecting binary container sections, disassemblies, and metadata.
* [**Package Management Commands**](file:///home/jehud/Projects/solix-language/docs/wiki/commands/package-commands.md): `solix new`, `solix install`, `solix uninstall`, and `solix list`.
