# Expression Keywords

Reserved keywords appearing within expressions, type relations, allocation, and operator definitions:

- [`new`](new.md), [`this`](this.md), [`super`](super.md) — Instantiation and receiver references
- [`extends`](extends.md), [`implements`](implements.md), [`instanceof`](instanceof.md) — Inheritance and type inspection
- [`sizeof`](sizeof.md), [`operator`](operator.md) — Size queries and operator overloading
