# Control Flow Keywords

Reserved keywords governing branching, loops, jumps, and exception handling:

- [`if`](if.md), [`else`](else.md) — Conditional branching
- [`switch`](switch.md), [`case`](case.md), [`default`](default.md) — Multi-way branch dispatch
- [`for`](for.md), [`while`](while.md), [`do`](do.md) — Loop constructs
- [`break`](break.md), [`continue`](continue.md), [`return`](return.md) — Control-flow jumps and function returns
- [`try`](try.md), [`catch`](catch.md), [`finally`](finally.md), [`throw`](throw.md) — Structured exception handling
