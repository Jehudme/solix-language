# Declaration Keywords

This section documents keywords defining structural symbols, types, and modules:

* **`class`**: Declares a nominal reference type with fields, methods, constructors, and destructors.
* **`interface`**: Declares an abstract contract defining bodiless method signatures.
* **`enum`**: Declares a 32-bit integer-backed nominal enumeration type.
* **`package`**: Declares the canonical namespace hierarchy for a translation unit.
* **`import`**: Brings symbols from another package into the local scope.
* **`alias`**: Defines an alternative identifier for a qualified symbol or complex type signature.
