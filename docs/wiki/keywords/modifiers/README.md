# Modifier Keywords

Reserved keywords controlling visibility, dispatch, memory ownership, and linkage:

- [`public`](public.md), [`private`](private.md), [`protected`](protected.md), [`internal`](internal.md) — Access visibility
- [`static`](static.md), [`const`](const.md), [`inline`](inline.md), [`native`](native.md) — Linkage and optimization hints
- [`abstract`](abstract.md), [`virtual`](virtual.md), [`override`](override.md) — Polymorphic dispatch
- [`weak`](weak.md) — Non-owning ARC cycle breaking
