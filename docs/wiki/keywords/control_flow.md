# Control Flow Keywords

This section documents keywords governing execution branching, iteration, and jump statements:

* **`if` / `else`**: Conditional branch based on a boolean condition expression.
* **`while`**: Evaluates boolean condition before loop iteration.
* **`do`**: Executes loop body at least once before testing condition.
* **`for`**: C-style three-clause loop (`for (init; cond; step)`).
* **`switch` / `case` / `default`**: Multi-way branching based on discrete integer or enum values.
* **`break`**: Exits the innermost loop or switch block immediately.
* **`continue`**: Skips remainder of loop body and steps to next iteration.
* **`return`**: Returns control (and optional value) from function.
* **`try` / `catch` / `finally`**: Table-driven zero-cost exception handling and unwinding blocks.
* **`throw`**: Raises an exception object and begins stack unwinding.
* **`assert`**: Debug invariant verification intrinsic.
* **`exit`**: Terminates process execution with numeric status code.
