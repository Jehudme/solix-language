# Toolchain & Editor Protocol Specifications

Formal behavioral and wire-protocol specifications for developer tools in the Solix toolchain.

- [**CLI Subcommands & Manifest (`cli/`)**](cli/README.md) — Subcommand contracts, exit codes, environment overrides, and `manifest.yaml` schema.
- [**Language Server Protocol (`lsp/`)**](lsp/README.md) — JSON-RPC 3.17 protocol transport, symbol navigation, diagnostics, and IDE intelligence.
