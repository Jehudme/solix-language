# Standard Library Specifications

This section contains formal specifications for the libraries distributed with the Solix toolchain.

- [**`solixlib` Standard Library (`solix@2.0.0`)**](solixlib/README.md) — Core strings, collections, streams, filesystem, JSON, cryptography, networking, compression, and VM telemetry.
- [**`raylib` Graphics & Audio Bindings**](raylib.md) — Raylib FFI bindings, vector/matrix/color/rectangle OOP ergonomics, RAII `Managed*` resource wrappers, and scoped rendering helpers.
