# Solix Standard Library Specification (`solixlib`)

The standard library specifications cover every module family shipped inside `solixlib`:

- [`string.md`](string.md) — `String`, `StringBuilder`, UTF-8 manipulation, and formatting
- [`list.md`](list.md) — Generic resizable `List<T>` dynamic array container
- [`map.md`](map.md) — Generic hash-bucket `Map<K, V>` associative container
- [`set.md`](set.md) — Generic hash-based `Set<T>` unique element set
- [`streams.md`](streams.md) — Abstract streams, byte streams, and memory buffers
- [`filesystem.md`](filesystem.md) — `File`, `Directory`, `Path`, and filesystem operations
- [`crypto.md`](crypto.md) — Cryptographic hashes (SHA-256, MD5) and secure random numbers
- [`time.md`](time.md) — Timestamps, duration, clock intervals, and calendar dates
- [`math.md`](math.md) — Trigonometric functions, exponentials, roots, and constants
- [`console.md`](console.md) — Console I/O, terminal styling, color formatting
- [`environment.md`](environment.md) — Environment variables, command line arguments, and process info
- [`exceptions.md`](exceptions.md) — Standard exception hierarchy, stack traces, and unwinding
- [`linear_collections.md`](linear_collections.md) — Stack, Queue, Deque, and linear buffers
- [`collections_core.md`](collections_core.md) — Collection interfaces, iterators, and enumeration contracts
- [`primitives.md`](primitives.md) — Primitive boxing wrappers, parsing, and bit-level inspection
- [`resource.md`](resource.md) — Embedded asset extraction from `.slxp` containers
- [`scaffolding.md`](scaffolding.md) — Project templates, boilerplate scaffolding, and test harnesses
- [`json.md`](json.md) — Structured JSON parsing and JSON pointer queries
- [`net.md`](net.md) — Cross-platform TCP/UDP sockets and HTTP client
- [`compress.md`](compress.md) — Gzip, Zlib, and Deflate buffer compression engines
- [`vm.md`](vm.md) — VM telemetry, memory inspection, and cycle collector controls
