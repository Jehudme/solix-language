# Solix Standard Library Specification (`solixlib`)

The standard library specifications have been expanded into granular, component-level specifications located in [`../libraries/solixlib/`](../libraries/solixlib/):

- [`string.md`](../libraries/solixlib/string.md) — `String`, `StringBuilder`, UTF-8 manipulation, and formatting
- [`list.md`](../libraries/solixlib/list.md) — Generic resizable `List<T>` dynamic array container
- [`map.md`](../libraries/solixlib/map.md) — Generic hash-bucket `Map<K, V>` associative container
- [`set.md`](../libraries/solixlib/set.md) — Generic hash-based `Set<T>` unique element set
- [`streams.md`](../libraries/solixlib/streams.md) — Abstract streams, byte streams, and memory buffers
- [`filesystem.md`](../libraries/solixlib/filesystem.md) — `File`, `Directory`, `Path`, and filesystem operations
- [`crypto.md`](../libraries/solixlib/crypto.md) — Cryptographic hashes (SHA-256, MD5) and secure random numbers
- [`time.md`](../libraries/solixlib/time.md) — Timestamps, duration, clock intervals, and calendar dates
- [`math.md`](../libraries/solixlib/math.md) — Trigonometric functions, exponentials, roots, and constants
- [`console.md`](../libraries/solixlib/console.md) — Console I/O, terminal styling, color formatting
- [`environment.md`](../libraries/solixlib/environment.md) — Environment variables, command line arguments, and process info
- [`exceptions.md`](../libraries/solixlib/exceptions.md) — Standard exception hierarchy, stack traces, and unwinding
- [`linear_collections.md`](../libraries/solixlib/linear_collections.md) — Stack, Queue, Deque, and linear buffers
- [`collections_core.md`](../libraries/solixlib/collections_core.md) — Collection interfaces, iterators, and enumeration contracts
- [`primitives.md`](../libraries/solixlib/primitives.md) — Primitive boxing wrappers, parsing, and bit-level inspection
- [`resource.md`](../libraries/solixlib/resource.md) — Embedded asset extraction from `.slxarc` containers
- [`scaffolding.md`](../libraries/solixlib/scaffolding.md) — Project templates, boilerplate scaffolding, and test harnesses
